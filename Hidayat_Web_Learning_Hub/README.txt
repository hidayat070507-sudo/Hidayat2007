HIDAYAT WEB LEARNING HUB

File:
- index.html
- css/style.css

Cara menggunakan:
1. Letakkan index.html dan folder css di folder utama proyek yang berisi file Pertemuan1.html, Pertemuan2.html, dan folder latihan.
2. Buka index.html menggunakan browser atau ekstensi Live Server di VS Code.
3. Website memiliki desain responsif untuk desktop/HP, menu mobile, animasi, pencarian materi, dan filter kategori.

Catatan:
Tautan materi menggunakan struktur folder dari kode yang dikirim. Jika nama atau lokasi file di komputer berbeda, sesuaikan atribut href di index.html.
