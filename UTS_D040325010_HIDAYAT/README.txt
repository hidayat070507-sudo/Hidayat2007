UTS PEMROGRAMAN WEB — PT PRIMA AKUNTINDO

Isi folder:
- login.html          : Halaman login dengan animasi CSS
- dashboard.html      : Dashboard ringkasan keuangan
- jurnal_umum.html    : Form input jurnal umum
- laba_rugi.html      : Tabel laporan laba rugi
- css/style.css       : External CSS bersama untuk seluruh halaman

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder hasil ekstrak di VS Code.
3. Buka login.html menggunakan browser atau ekstensi Live Server.
4. Navigasi halaman tersedia melalui menu sidebar.

Catatan:
Form dan data transaksi adalah contoh tampilan front-end untuk tugas HTML/CSS.
Belum terhubung ke database atau sistem autentikasi sungguhan.
